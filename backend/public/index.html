Same query, two plans

Every figure on this page comes from MongoDB. This runs one real query, all events for one account newest first, twice: once forced to read the whole collection, once through the compound index. Each plan runs three times and the time shown is the median.

db.events.find({ "actor.login": user })
  .sort({ created_at: -1 })
  .hint({ $natural: 1 })   // full scan
  .hint("actor_time")      // { "actor.login": 1, created_at: -1 }
